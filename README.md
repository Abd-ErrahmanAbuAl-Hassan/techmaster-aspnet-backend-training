## Prerequisites

- .NET SDK (recommended: 7 / 8 / 9) installed and `dotnet` on PATH
- An editor such as Visual Studio or Visual Studio Code

---

## How to run a task

1. Open a terminal and change to the task folder, for example:

```powershell
cd "Phase 01 - Backend foundations/Task 01 - csharp-drills"
```

2. Run the project using the .NET CLI:

```powershell
dotnet run --project "Task 01 - csharp-drills.csproj"
```

Each task folder includes its own README with specific instructions
and examples.

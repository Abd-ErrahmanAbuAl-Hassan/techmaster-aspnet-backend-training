# Task 04 - Book Store API Mini-Project

A comprehensive REST API for managing a book store system with books, authors, and categories.

## Project Overview

This is Phase 02 project that demonstrates building a review-ready API with multiple related resources. The system uses in-memory storage but is structured to easily integrate with Entity Framework Core in Phase 03.

## Features

### ✅ Implemented Features

- **Authors API**: Manage authors with full CRUD operations
- **Categories API**: Manage book categories with active/inactive status
- **Books API**: Complete book management with relationships
- **Search & Pagination**: Advanced search by title/ISBN and filters
- **Reports & Summary**: Generate management statistics
- **Unified Result Pattern**: All services return consistent Result<T> objects
- **Validation**: Comprehensive business rule validation
- **Error Handling**: Proper HTTP status codes and error messages
